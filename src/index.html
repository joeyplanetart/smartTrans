功能与更新

      
smartTrans · v0.3.11

      
功能清单

      
    
        
  • 单词与短句收藏保存中英文、来源和备注，支持搜索、编辑、朗读与取消收藏。
    • 
        
  • 中英双向翻译全文或选区翻译，保留原意与简单 Markdown 格式。
    • 
        
  • 直接整理译文复制、插入、替换，支持撤销与重做。
    • 
        
  • Jira 左右对照读取标题、描述与可见评论，保留作者和时间，配对滚动。
    • 
        
  • 英文朗读选中原文或译文听发音，支持语速切换、右键与快捷键。
    • 
        
  • 个人英语学习20 天渐进路径，词汇、语法、听说读写练习，错题复习与 AI 反馈。
    • 
        
  • 桌面快捷操作菜单栏常驻、全局唤起、剪贴板翻译与本机内容保存。
    • 
      

      
版本更新记录

      
v0.3.11 当前版本
  • 新增本机收藏本，支持搜索、编辑释义、备注和朗读。
  • 支持选区右键收藏、翻译结果一键收藏，以及重复提示和取消收藏撤销。

      
v0.3.10
  • 为英语学习中的 600 个词汇添加美式音标，可配合朗读按钮学习发音。

      
v0.3.9
  • 英语学习扩展为每天 30 个词汇、3 道语法题；词汇按每组 10 个浏览。
  • 完整路径包含 600 个不重复词汇和 60 道语法题，保留已有学习记录。

      
v0.3.8
  • 修复学习页「听发音」无声的问题，并显示朗读状态或错误原因。

      
v0.3.7
  • 新增个人英语学习板块、20 天渐进路径和本机学习进度。
  • 加入错题复习、知识追踪、即时翻译及 AI 写作反馈与复盘。

      
v0.3.6
  • 设置中新增文本翻译的上下 / 左右布局切换，默认上下布局。
  • 记住布局偏好，Mini 模式与窄窗口自动适配上下布局。

      
v0.3.5
  • 顶部说明移至品牌旁，与右侧功能菜单分开。
  • Mini 模式新增置顶开关，切换其他应用时保持可见。

      
v0.3.4
  • 新增 Mini 窗口，聚焦输入、翻译结果与英文朗读。
  • 支持快捷键切换，返回时恢复完整窗口大小和工作模式。

      
v0.3.3
  • 简化编辑区顶部文案，调整垂直居中与高度。
  • 移除逐字母拼读，保留英文朗读与语速控制。
  • 新增功能清单与版本更新记录。

      
v0.3.2
  • 新增 macOS 英文朗读、语速选择与停止播放。
  • 支持编辑区、译文和 Jira 内容选区朗读。

      
v0.3.1
  • Jira 评论加入翻译与左右对照。
  • 支持评论分页，显示作者、发布时间与编辑时间。

      
v0.3.0
  • 支持 Jira 标题、描述读取与左右对照翻译。
  • 支持 API Token 连接与浏览器数据导入。
  • Jira 翻译放宽 Markdown 校验，保留链接、代码与段落对齐。
