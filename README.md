# smartTrans

Bun + Electron 桌面翻译工具。只支持中文和英文，在一个内容面板里编辑、翻译、插入或替换。翻译由本机已登录的 Codex CLI 或 Cursor CLI 完成，无需在应用里填写 API Key。

## 运行

    bun install
    bun run start

## macOS 图标启动

已安装的版本位于 `/Applications/smartTrans.app`，可从 Finder 的「应用程序」中双击打开，也可以将它拖到 Dock。

重新打包：

    bun run package:mac

产物为 `dist/smartTrans.app`，自带 Electron 运行环境。将它复制到「应用程序」即可安装。该包使用本机临时签名，适合本机使用；对外分发需要 Apple Developer 签名和公证。翻译仍需要本机安装并登录 CLI。

图标源文件为 `scripts/make-icon.swift`，应用图标为 `assets/smartTrans.icns`。

需要预先安装并登录至少一个命令行工具：

- Codex CLI：运行 `codex login`
- Cursor CLI：运行 `agent login`

可在应用右上角「设置」中切换工具。若从 Finder 启动 Electron，应用也会查找常见的 CLI 安装路径。

本项目显式选择适合简单翻译的低成本模型：

- Codex CLI：`gpt-6-luna`，`model_reasoning_effort="low"`。
- Cursor CLI：`claude-haiku-5-5-low`，不启用思考。

这些参数只用于本应用的翻译请求。模型不可用时会报错，不会自动切换到更贵的模型。实际扣费或额度消耗以对应账号套餐为准。

## 使用

### 个人英语学习

点击顶部「英语学习」进入独立学习页。以高中英语基础为起点，安排 4 周、20 天的渐进路径。每周从日常基础、生活沟通、观点表达推进到进阶运用；每天学习 30 个词汇（分成 3 组，每组 10 个），完成 3 道不同的语法题，以及听力与跟读、阅读理解和短写作。全路径共 600 个不重复词汇和 60 道语法题。

每个词汇显示美式 IPA 音标，并可点击「听发音」。音标摘自 [open-dict-data/ipa-dict](https://github.com/open-dict-data/ipa-dict) 的 en_US 词库，按词义选择常用读法；授权见 `src/vendor/LICENSE.ipa-dict.txt`。

学习页可输入英文自动获取中文翻译，并播放原文发音。语法和阅读错题自动进入错题本，答对后清除；知识追踪按六项练习的完成情况显示进度。写作可调用设置中选定的本机 AI CLI 获取中文修改建议，AI 复盘会结合已完成天数、词汇和错题给出下一次练习建议。学习记录保存在本机浏览器存储中；跟读由本人标记完成，目前不自动评判发音。提醒和鼓励通知留待后续版本。

### Jira 左右对照

切换到「Jira 对照」，粘贴 `https://站点.atlassian.net/browse/WEB-123`。支持读取标题、描述及当前账号可见的评论，将内容排成左右配对的行，两列共用滚动区域。评论按发布时间排序，保留作者、发布时间和编辑时间，这些信息不发送给模型翻译。默认译为中文，也可切换为英语；支持流式显示、取消和复制译文（含评论及作者、时间）。

连接方式：

1. **直接读取**：点击「连接 Jira」，填写 Atlassian 邮箱和 API Token，选择 Scoped 或经典 Token 类型。Scoped Token 的 Cloud ID 会自动读取，失败时可手动填写。连接验证成功后即可读取链接。默认 Token 仅保留在本次运行；只有勾选「在本机加密保存」时，才通过 Electron safeStorage 加密后写入应用数据目录。可在连接设置中移除。
2. **浏览器导入**：无需配置 Token。点击「浏览器导入」，在日常已登录的浏览器中打开只读票据数据页，全选复制 JSON，返回后点「导入剪贴板数据」。若 JSON 插件将页面折叠，可用 Chrome 的 `⌘⌥U` 查看源代码后复制。导入时会核对票据编号。

应用不使用内嵌 Atlassian 登录窗口。浏览器登录状态不会自动授权应用；浏览器导入使用用户手动复制的数据。连接凭据只发往对应的 Atlassian 站点或官方 API 网关，不会发送给翻译模型。读取接口仅使用 GET，并设置 `updateHistory=false`；不会写回或修改 Jira 票据。

API 读取会自动分页拉取所有可见评论；若 Token 缺少评论读取权限会明确报错。浏览器导入会检查已导入评论数量；若还有下一页，点击「导入更多评论」打开对应数据页，复制 JSON 后再次点击「导入剪贴板数据」合并。旧版浏览器数据没有评论字段时，可点击「导入评论」补充。尚未导入完整评论时会显示提醒，复制按钮标为「复制当前译文」。

当前不包括独立自定义字段和图片 OCR。图片、附件和不支持的扩展内容会提示在原页核对。长文按组翻译，遇到超过单次上限的单段会明确报错，不静默截断。Jira 模式不执行严格 Markdown 结构校验，允许换行、列表和强调样式有所变化；仅保护链接、代码、技术字段名及段落对齐标识。普通文本模式继续保留 Markdown 校验。

Jira 导入内容与普通编辑区分开，切换模式不会覆盖原先的文字。最近使用的链接和模式保存在本机，导入的票据与对照结果仅保留在当前运行中。

认证依据：[Atlassian API Token 文档](https://support.atlassian.com/atlassian-account/docs/manage-api-tokens-for-your-atlassian-account/)。Scoped Token 使用官方 `api.atlassian.com/ex/jira/{cloudId}` 网关。

### 文本翻译

输入或粘贴中文、英文内容。选中文本时只翻译选区；不选中时翻译全文。目标语言会自动判断，也可手动切换。译文出来后可插入原文后、替换原文，或复制。

- 逐步显示译文，显示引擎就绪、首字和总耗时，生成中可以取消。格式校验完成后才允许应用译文。
- Codex 使用本机 CLI 的 app-server 流式接口，复用后台进程；每次翻译使用独立临时会话。Cursor 使用 stream-json 增量输出。
- 最近 30 条相同内容、目标语言和模型的译文缓存在本次进程内；退出后清除，取消或校验失败的结果不会缓存。
- 代码块、行内代码、链接地址、标题与列表标记、换行等会先被保护，再逐一校验、还原；校验失败时保留原文。
- 按中文字符和英文词的占比识别主要语言，并显示混排提示；可手动覆盖翻译方向。
- 插入、替换和剪贴板导入各作为独立编辑步骤，支持撤销与重做；修改后提供直接撤销按钮。
- 菜单栏「译」可打开窗口、翻译剪贴板或退出。关闭窗口时应用留在菜单栏。
- 剪贴板翻译会将文字追加到现有内容后，选中新增部分进行翻译；可撤销追加操作。

快捷键：

- `⌘/Ctrl + Enter`：翻译
- `⌘/Ctrl + Shift + Enter`：替换原文
- `Alt + Enter`：插入译文
- `Esc`：取消当前翻译或关闭译文
- `⌘/Ctrl + Z` / `⌘/Ctrl + Shift + Z`：撤销 / 重做
- `⌘/Ctrl + Shift + T`：全局唤起窗口
- `⌘/Ctrl + Shift + Y`：全局翻译剪贴板

设置中可查看全局快捷键是否注册成功；若组合被其他软件占用，可使用应用的「翻译」菜单或菜单栏「译」操作。

运行 `bun test` 验证 Markdown 保护、撤销历史和语言识别；运行 `bun run check` 检查脚本语法。

内容保存在当前设备的应用本地存储。翻译会发送到所选 CLI 对应的 AI 服务；CLI 运行在只读模式，以避免翻译文本触发文件修改。

### 英文朗读（macOS）

在内容编辑区、翻译结果或 Jira 左右对照中选中英文，点击「朗读选中内容」或右键「朗读英文」。`⌘/Ctrl + Shift + S` 朗读选区，`Esc` 或「停止」结束播放。支持慢速、正常、快速，语速保存在本机。

使用 macOS 自带 Samantha 英语语音，不经过 AI CLI，不需要额外付费服务。单次朗读最多 4000 字符。若语音不可用，请在 macOS 系统设置中安装 Samantha 英语语音。新朗读会停止上一条，关闭窗口或退出应用也会停止。

点击应用右上角「功能与更新」查看当前版本、功能清单与版本更新记录。仓库中的完整记录见 [CHANGELOG.md](CHANGELOG.md)。

### Mini 窗口

点击右上角「Mini 模式」或按 `⌘/Ctrl + Shift + M`，切换为约 460 × 640 的小窗口。只显示输入、翻译、结果操作和英文朗读；保留原有内容与译文。点击「完整窗口」恢复原窗口大小和位置。进入 Mini 前若处于 Jira 模式，会暂时切换到文本翻译；返回时恢复 Jira 对照（正在翻译文本时优先保留当前操作，可完成后手动切回 Jira）。Mini 窗口可自由移动与缩放，Jira 正在读取或翻译时请先完成或取消再切换。

Mini 顶部的「置顶」可让窗口保持在其他普通应用窗口上方，再点「已置顶」取消；返回完整窗口会自动取消置顶。置顶不会阻止你操作其他应用。

### 文本翻译布局

在「设置 → 原文与译文布局」中选择上下布局或左右布局。默认上下布局，选择后即时生效并保存在本机。左右布局将原文放在左侧、译文放在右侧；Mini 模式和宽度不超过 800px 的窗口自动使用上下布局，回到宽窗口后恢复偏好。切换不会清空原文或译文，Jira 对照布局保持不变。

### 收藏本

点击顶部「☆ 收藏本」可查看单词和短句。支持按英文、中文释义、备注或来源搜索，编辑、听发音和取消收藏；取消后可立即撤销最近一条。选中文本、译文、Jira 或英语学习内容后右键「收藏单词 / 短句」，或者在翻译结果中点击「☆ 收藏」保存原文和译文。选区收藏可手动补充释义，保存收藏本身不调用 AI。英文内容忽略大小写、空白和全半角差异查重，重复时保留原记录，可选择编辑已有记录。

Mini 模式支持右键收藏；查看完整收藏本需切回完整窗口。数据保存在 `~/Library/Application Support/smart-translation/favorites.json`，采用临时文件替换方式保存，不上传或写入 Git。单条英文最多 2000 字符，释义 4000 字符，备注 2000 字符；最多 5000 条。收藏文件损坏时会明确报错并保留文件，不会自动清空。
